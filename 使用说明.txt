暗区战绩 · KD 计数器 1.2.1

双击 ABI-KD-1.2.1.exe 即可使用，不需要安装 Python、不需要账号或 API Key。
首次启动会解压内置组件，稍等片刻。此版本适用于 Windows 10/11 64 位。

数据初始化与升级
公开发行版不含任何个人战绩或游戏截图，新用户从空数据库开始。
已有用户继续使用 %LOCALAPPDATA%\ABI-KD 中的数据，无需迁移；不会重置或覆盖。
主页仅显示战局数、普通/封锁/强化封锁三列 KD、击败特遣队员数。
自动采集范围是游戏当前可见历史；已经不再展示的旧对局仍保留在本机数据库。

自动采集历史战绩（1.2 新增）
1. 保持一个暗区突围无限游戏窗口运行，先打开个人主页 → 历史战绩。
   已在个人主页其他标签时会自动切到历史战绩；已在个人作战报告时会自动返回。
2. 点击软件右上角“自动采集”，再点击“开始自动采集”。
3. 程序先扫描全部历史条目建立清单，再逐一展开行、点击作战报告、保存截图、读取数据、返回并翻页。
   日期来自历史列表，年份按当前日期推断；跨年记录会回推上一年。
4. 请勿操作鼠标或切换窗口。F8 随时停止，切换窗口、最小化游戏或改变窗口大小也会停止。
5. 连续两次向下滚动后列表不再变化、且清单内每场都有报告，才标记全部完成；异常停止会保留已采集结果，不能视为全部完成。
6. 结果保存到数据目录 captures 下的独立批次文件夹，不直接写入战绩数据库。
7. 采集结果分为新增、已有记录、待核对；已有同时间/模式/地图/难度记录不会被覆盖。
   数值不同的已有记录会提示冲突，原记录保持不变；请到历史战绩中自行核对。
8. 双击行可查看截图及修改识别字段；完整新增记录默认选中，待核对和已有记录默认不选。
9. 下方可预览合并后的三项数据。核对并勾选确认后，点击“合并选中新增记录”。
   合并前自动备份；只有此操作才会添加到当前数据库。关闭窗口仍保留采集结果。
10. “查看上次采集结果”可重新打开最近批次。中断后点击“继续上次采集”，会回到顶部检查列表并跳过本批次已采集的报告。
    点击“开始自动采集”会新建一个批次，重新读取全部可见对局。

自动采集适配当前中文界面、居中的 16:9 游戏画面（包括本机 1440×1080 黑边画面）。
未适配的新布局、遮挡、低清或未加载页面会停止或进入待核对，请勿当成已全部采集。
软件仅对游戏窗口截图并发送普通鼠标点击/滚轮，不读取游戏内存或注入进程。

每次游戏后也可手动导入截图
1. 截取个人“作战报告”，保留模式地图标题、行动结果、淘汰特遣队员数。
2. 拖入软件，或点击“导入作战报告”多选，也可复制截图后 Ctrl+V。
3. 软件在本机自动识别，核对后保存，统计立即更新。
4. 作战报告通常不含对局日期。标题里的 18:30 是时长；导入时间默认当前时间，必须核对。
5. 历史列表只有总淘汰数（含 AI），不足以确定特遣队员数，请使用个人作战报告。
6. 低清、裁剪、其他语言或游戏更新后的布局可能需要手工修正；未知数据保留为待核对。

统计口径
只记录特遣队员淘汰数，不统计 AI。
撤离 KD = 特遣队员淘汰数 / 撤离失败场次（包括行动终止）。这是本软件明示的统计口径，
不宣称等同于游戏内官方全生涯 KD；撤离失败并不在所有特殊情形下等同于角色被击败。
团队模式的 KD = 淘汰数 / 报告中的实际被击败次数，独立于撤离类。
淘汰数或撤离结果（团队为被击败次数）未知的场次不计入 KD。
战局数包含范围内全部记录；击败特遣队员数累加已知淘汰，不把未知值补为零。
KD 显示一位小数，整数省略小数；鼠标悬停可查看精确值、公式与完整样本数。
分母为 0 且有淘汰时显示 ∞；没有可计算样本或 0/0 时显示 —。
历史页的地图、难度、日期、模式和搜索筛选影响历史列表与 CSV 导出。
主页始终显示全部常规难度，不受历史页筛选影响。

防重复和保存
完全相同图片以 SHA-256 去重；同一时刻、地图、模式及战绩的记录也会拦截。
重新裁剪或压缩图片可能产生不同哈希，务必核对日期，避免同一局重复录入。
数据存储于 %LOCALAPPDATA%\ABI-KD，移动或更新 EXE 不会丢失战绩。
SQLite 数据库：matches.sqlite3；原图：images 文件夹；错误日志：app.log。
“备份”包含所有战绩和对应截图。“恢复备份”按记录 ID 合并，相同 ID 以备份为准；
恢复之前自动保存一份当前数据。建议定期备份到另一块磁盘。
CSV 为 UTF-8 BOM，Excel 可直接打开。CSV 仅导出当前筛选结果，不作为恢复文件。

手动导入仅处理你选择的截图；自动采集只有点击开始后才操作游戏历史页面。
软件不会读取游戏内存或注入进程。
OCR 在本地运行，无联网识别、遥测或截图上传。关闭软件前请等待当前识别完成。
